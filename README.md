# 카페 오늘 — 랜딩 페이지

가상의 동네 카페 **"카페 오늘"**을 소개하는 한 페이지짜리 웹사이트입니다.
빌드 도구나 라이브러리 없이 HTML, CSS, JavaScript만으로 만들었습니다.

**사이트 보기:** https://sohansin101090-ship-it.github.io/cafe-landing/

## 페이지 구성

- **히어로** — 카페 이름과 소개 문구, "오늘의 메뉴 보기" 버튼
- **오늘의 메뉴** — 버튼을 누르면 펼쳐지는 메뉴와 가격
- **영업 정보** — 영업시간과 위치
- **푸터**

## 폴더 구조

| 파일 | 설명 |
| --- | --- |
| `index.html` | 페이지 구조와 내용 (메뉴, 가격, 영업시간 등) |
| `style.css` | 색상, 글꼴, 레이아웃 스타일 |
| `script.js` | 메뉴 펼치기/접기 버튼 동작 |
| `README.md` | 이 설명 파일 |

## 로컬에서 보기

`index.html`을 브라우저로 열면 바로 볼 수 있습니다. 설치할 것은 없습니다.

## 수정하고 배포하기

이 레포는 GitHub Pages로 배포됩니다. `main` 브랜치의 루트 폴더가 그대로 사이트가 됩니다.

```bash
# 파일 수정 후
git add .
git commit -m "메뉴 가격 변경"
git push
```

push하고 1~2분 정도 지나면 사이트에 반영됩니다.
